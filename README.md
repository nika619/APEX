# APEX — Performance Training OS

A complete training companion in a single HTML file: plan a session, log every set, watch your readiness and fatigue, and try the coach chat interface. No build step, no install, no backend.

## Features

- **Readiness score** with an animated gauge, so you know whether today is a push day or a recovery day
- **Live session mode:** exercise queue, set logging, skip/next, workout timer and an automatic rest timer
- **Progressive overload tracking** with personal records per lift
- **Analytics:** fitness-vs-fatigue curve, training load and volume charts over 30, 60 or 90 days, plus a training-consistency heatmap
- **Muscle map** that highlights the muscle groups each exercise works
- **Coach chat UI** with quick-reply chips and a voice-input button (prototype: replies are sample responses, ready to wire to an LLM)
- **Custom exercises** and plans, light/dark theme, and data saved locally in your browser

## Run it

Open `index.html` in any modern browser. That's it.

```bash
git clone https://github.com/nika619/APEX-Performance-Training-OS.git
start APEX-Performance-Training-OS/index.html   # Windows (use `open` on macOS)
```

Vanilla HTML, CSS and JavaScript · Canvas charts · localStorage
